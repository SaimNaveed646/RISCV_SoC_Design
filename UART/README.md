# Baud Generator – UART

## 1. Overview

The Baud Generator is a Verilog hardware module used in a UART (Universal Asynchronous Receiver/Transmitter) system. It generates a periodic `BaudTick` signal based on the system clock frequency and the desired UART baud rate.

The `BaudTick` signal is used by the UART transmitter and receiver to control the timing of serial data transmission and reception.

## 2. Module Interface

**Module Name:** `BaudGenerator`

| Signal | Direction | Description |
|---|---|---|
| `CLK` | Input | System clock |
| `Reset` | Input | Active-high synchronous reset |
| `BaudTick` | Output | One-clock-cycle baud timing pulse |

### Parameters

| Parameter | Default Value | Description |
|---|---|---|
| `CLK_FREQ` | 50,000,000 Hz | System clock frequency |
| `BAUD_RATE` | 9,600 bps | Desired UART baud rate |

## 3. Timing Calculation

- `CLK_FREQ:` The number of clock cycles generated by the FPGA per second.
- `BAUD_RATE:` The number of bits transmitted per second during UART communication. For standard binary UART, 9600 baud means 9600 bits per second.

The approximate number of system clock cycles required for one UART bit period is:

`CLKS_PER_BIT = CLK_FREQ / BAUD_RATE`

For a 50 MHz system clock and a baud rate of 9600:

`CLKS_PER_BIT = 50,000,000 / 9,600 = 5208`

For the default configuration:

- **System clock frequency:** 50 MHz
- **System clock period:** 1\50 MHz = 20 ns
- **Clock cycles per baud tick:** 5208
- **Baud tick period:** 104.16 µs
- **Effective baud rate:** Approximately 9600.61 baud



# UART Transmitter (Verilog)

## UART Frame Format

Each transmitted frame consists of 11 bits.

| Field | Size | Description |
|---|---:|---|
| Start Bit | 1 bit | Logic `0` |
| Data Bits | 8 bits | Transmitted LSB first |
| Parity Bit | 1 bit | Odd parity |
| Stop Bit | 1 bit | Logic `1` |

**Note:** The transmitter generates the parity bit using `~(^tx_data)`, which produces odd parity across the data and parity fields.

## Module Interface

### Inputs

| Signal | Width | Description |
|---|---:|---|
| `CLK` | 1 bit | System clock |
| `Reset` | 1 bit | Synchronous active-high reset |
| `BaudTick` | 1 bit | Timing pulse indicating the next UART bit interval |
| `tx_start` | 1 bit | Request to start transmission |
| `tx_data` | 8 bits | Parallel data to transmit |

### Outputs

| Signal | Width | Description |
|---|---:|---|
| `tx` | 1 bit | Serial transmission output |
| `busy` | 1 bit | High while transmission is in progress |
| `tx_done` | 1 bit | One-clock-cycle pulse when transmission completes |

## Finite State Machine (FSM)

The transmitter uses five states to control the transmission sequence.

| State | Operation |
|---|---|
| `IDLE` | Waits for `tx_start` and captures the input data |
| `START` | Holds the start bit interval and then outputs the first data bit |
| `DATA` | Transmits eight data bits, LSB first |
| `PARITY` | Transmits the generated odd parity bit |
| `STOP` | Provides the stop bit interval and signals completion |
